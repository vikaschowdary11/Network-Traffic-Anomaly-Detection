# Network Traffic Anomaly Detection

## Overview

An unsupervised machine learning system developed to detect anomalous network traffic using the NSL-KDD dataset.

## Objectives

- Identify abnormal patterns in network traffic.
- Apply unsupervised machine learning for anomaly detection.
- Analyze network traffic features to distinguish normal and anomalous activity.

## Algorithm

Isolation Forest

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Methodology

1. Loaded and explored the NSL-KDD dataset.
2. Performed data preprocessing and feature selection.
3. Applied feature scaling to prepare the data.
4. Trained an Isolation Forest model for anomaly detection.
5. Evaluated the detected anomalies using performance metrics and confusion matrix analysis.

## Project Files

- `Network_Traffic_Anomaly_Detection.ipynb` - Complete project notebook containing the code, analysis, visualizations, and results.

## Dataset

NSL-KDD dataset

## Results

The model was evaluated using classification metrics and confusion matrix analysis to assess its ability to identify anomalous network traffic.
